# Stage 2 — Shim, pools and well-known types: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Descriptor sets load into pools that R can list, through the one
header that touches upb.

**Architecture:** `src/zpb_upb.h` is the only file that includes
`upb/ruby-upb.h`. A pool is a finalised external pointer to a
`upb_DefPool` plus an R environment recording each added file's
serialised bytes (for the identical/conflict rule). C never raises R
errors while upb is on the stack: C entry points return a status the R
side turns into a classed condition.

**Tech Stack:** C99, R (>= 4.1) base only, testthat 3; `protoc` (Homebrew)
for tool-generated descriptor sets.

**Spec:** `.agents/roadmap.md` § Stage 2; `.agents/design.md` §8, §9.3,
§11, §18 question 7 (decided 2026-10-25, see Task 0).

## Global Constraints

- No `Imports`; base R only. Conditions inherit `zuproto_error`.
- Descriptor sets are trusted input (§8): validation is upb's, plus the
  identical/conflict and missing-import rules.
- Internal C symbols `zpb_` / `ZPB_`; only `R_init_zuproto` exported.
- No R API call while a upb call is in progress; every upb arena owned by
  an external pointer or freed before any R allocation that can fail.
- `inst/descriptors/wkt.binpb` comes from protoc on the pinned tag's
  `.proto` files, never hand-made.

## Review Focus

- A `FileDescriptorSet` listing files in reverse dependency order: must
  load (topological order), not fail on the first file.
- The same file added twice from two sets: skipped if byte-identical,
  `zuproto_pool_conflict` if not, naming the file.
- An import neither in the set nor the pool: `zuproto_pool_error` naming
  the missing file and the file that imports it.
- Garbage bytes, an empty raw vector, a missing path: `zuproto_pool_error`
  / `zuproto_io_error`, never a crash; empty input is an empty set.
- A pool object after `saveRDS()`/`readRDS()` (null external pointer):
  `zuproto_invalid_argument`, not a segfault.
